# MY DIWALI DAY 2026

A premium dark-and-gold React memory website for one unforgettable Diwali day.

## Run locally

```bash
npm install
npm run dev
```

Vite serves the site at the local preview port configured for this session. For a production check, run `npm run build`.

## Replace photographs

Drop your own images into `public/assets/images/` while keeping the exact filenames below. You do not need to edit any React components.

- `my-photo-1.jpg`, `my-photo-2.jpg`, `my-photo-3.jpg`
- `family-1.jpg`, `family-2.jpg`, `family-3.jpg`
- `friends-1.jpg`, `friends-2.jpg`, `friends-3.jpg`
- `food-1.jpg`, `food-2.jpg`, `food-3.jpg`

## Replace videos

Drop your own recordings into `public/assets/videos/` and keep these names:

- `crackers-1.mp4`
- `crackers-2.mp4`
- `crackers-3.mp4`

The videos use native controls, support sound, and never autoplay.

## Interactions included

The opening screen is a real click-to-ignite rocket interaction. It sequences ignition, flight, return/explosion, and the Home transition. Sound is generated only after user interaction and can be toggled at any time. The site also includes mobile navigation, page navigation, smooth scrolling, timeline cards, gallery filtering, image lightbox, video controls, floating particles, animated fireworks, and back-to-top.

## Project structure

The app lives in `src/` with reusable components, data, pages, and global styling. Static route declarations are in `public/manus-routes.json`. The project does not require a backend or database.
