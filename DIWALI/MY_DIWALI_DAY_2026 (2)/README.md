# MY DIWALI DAY 2026

A premium dark-and-gold React memory website.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open Terminal and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL shown by Vite (usually http://127.0.0.1:5173).

For a production check: `npm run build`.

## Replace photographs
Replace the sample images in `public/assets/images/` using the same filenames:
- my-photo-1.jpg, my-photo-2.jpg, my-photo-3.jpg
- family-1.jpg, family-2.jpg, family-3.jpg
- friends-1.jpg, friends-2.jpg, friends-3.jpg
- food-1.jpg, food-2.jpg, food-3.jpg

## Replace videos
Put your own MP4 videos in `public/assets/videos/` with these names:
- crackers-1.mp4
- crackers-2.mp4
- crackers-3.mp4

The video cards have native controls and do not autoplay. The initial video files are safe placeholder instructions; replace them with your recordings.

## Features
Rocket intro with optional generated sound effects, responsive navigation, five routed pages, personal timeline, category-filtered photo gallery with lightbox, video gallery, and back-to-top.
