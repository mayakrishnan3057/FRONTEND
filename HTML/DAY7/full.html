WHAT IS HTML?

    HTML stands for HyperText Markup Language. It is the standard language used to create and structure web pages.

  • Hyper text

    • ext means text that can contain a link to another page or resource.

  • Markup

    • Markup means using tags to mark and structure content.

  • Language

    • Language means a set of rules and syntax used to communicate instructions.HTML has its own rules and tags that browsers understand.

    Website and HTML

    Website and HTML are not the same.
    Website → The complete collection of web pages that users visit.
    HTML → One of the languages used to create and structure those web pages.

    Example:

What is the <div> Tag?

The <div> tag is a non-semantic block-level container element in HTML5. It is used to group and organize other HTML elements together.

Example:

<div>
    <h1>Welcome</h1>
    <p>This is a paragraph inside a div element.</p>
</div>

In this example, the <div> element acts as a container for the <h1> and <p> elements.

Uses of the <div> Tag:

  • To group multiple HTML elements together.
  • To organize the structure of a webpage.
  • To apply CSS styles to a group of elements.
  • To create sections and layouts on a webpage.

    What are HTML Lists?

    HTML lists are used to display a group of related items in an organized way. There are three main types of lists in HTML5.

    Types of HTML Lists:

    • Unordered List
    • Ordered List
    • Description List

    1. Unordered List

    An unordered list displays items using bullet points. The <ul> tag is used to create an unordered list, and the <li> tag is used to define each list item.

    Example:

    <ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

    2. Ordered List

    An ordered list displays items in a numbered order. The <ol> tag is used to create an ordered list, and the <li> tag is used to define each list item.

    Example:

    <ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>

    3. Description List

    A description list is used to display terms and their descriptions. The <dl> tag defines the list, the <dt> tag defines the term, and the <dd> tag defines the description.

    Example:

    <dl>
    <dt>HTML</dt>
    <dd>HTML is used to create the structure of a webpage.</dd>

    <dt>CSS</dt>
    <dd>CSS is used to style a webpage.</dd>
</dl>

What is an HTML Table?

An HTML table is used to display data in rows and columns. The <table> tag is used to create a table in HTML5.

Main Table Tags:

  • <table> - Defines the table.
  • <tr> - Defines a table row.
  • <th> - Defines a table header cell.
  • <td> - Defines a table data cell.

Example:

<table>
    <tr>
        <th>Name</th>
        <th>Age</th>
        <th>City</th>
    </tr>

    <tr>
        <td>John</td>
        <td>25</td>
        <td>Chennai</td>
    </tr>

    <tr>
        <td>David</td>
        <td>30</td>
        <td>Mumbai</td>
    </tr>
</table>

Table Output:

``` ```
Name Age City
John 25 Chennai
David 30 Mumbai

In this example, the table contains rows and columns. The <tr> tag creates each row, the <th> tag creates header cells, and the <td> tag creates data cells.

What is an HTML Form?

    • <form> - Defines a form.
    • <label> - Defines a label for an input field.
    • <input> - Creates an input field.
    • <textarea> - Creates a multi-line text input area.
    • <select> - Creates a drop-down list.
    • <option> - Defines an option inside a drop-down list.
    • <button> - Creates a clickable button.
